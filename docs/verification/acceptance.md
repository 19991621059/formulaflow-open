# 0.1.0 验收记录

日期：2026-10-14（北京时间）。范围：独立开源项目的本机生产构建、真实模型 HTTP 流程和浏览器操作。使用自制公开示例，没有上传私人文件。

## 真实模型

模型为 `glm-5.3-flash`，通过助手的 `/api/process` 接口调用智谱通用接口；并非直接调用供应商后手动填入页面。

| 输入               | 模型处理耗时 | 检查结果                                                     |
| ------------------ | ------------ | ------------------------------------------------------------ |
| 公开微积分笔记图片 | 4.166 秒     | 识别标题、中文正文、定积分和导数表；5 个公式，语法检查无错误 |
| 高斯积分图片       | 1.566 秒     | 识别积分、指数和根号 π；1 个公式，语法检查无错误             |

两种内容均完成：上传 → 真实视觉识别 → 修改 → 预览 → Word 导出 → 源码导出。Word XML 中包含修改后的内容、原生 `m:oMath`；文档示例还包含 `w:tbl`。没有公式图片或 altChunk HTML 代替公式。

本次电脑的代理使用 fake-IP DNS，官方域名解析到保留地址。本机验证环境显式允许了私有地址；仓库示例的默认值仍为 false。密钥仅放在被 Git 忽略、权限为 600 的本地配置中。

## 实际浏览器操作

使用可自动化的 Codex 浏览器进行以下操作，截图由实际页面捕获：

1. 通过文件选择器上传公开文档图片；开始识别，观察真实阶段与等待时间，约 4 秒得到结果。
2. 编辑稿件，把积分中的 `x^2` 人为改成 `x^3`，测试对照原图复核。
3. 约 6 秒后生成建议稿；建议恢复 `x^2`。提案弹窗保留当前稿与建议稿，点击「接受提案」后确认修改应用。
4. 将标题改为「微积分课堂笔记（已核对）」，点击导出并完成浏览器实际下载。
5. 检查这个下载文件：包含修改后的标题、5 个 Office 原生公式和真实表格。可下载 [同一导出样例](sample-output.docx) 自行打开检查。
6. 验证原图放大、Escape 关闭、左右方向键切换结果页签。
7. 在 390 × 844 视口验证布局，页面内容宽度没有超过视口；保存移动端截图。

## 未验证的范围

- WPS 桌面窗口自动化不稳定，未完成桌面内继续编辑、保存和重新打开的交互验收；目前确认的是实际下载及 Word 原生内容结构，不把这两者说成桌面编辑验收。
- 未在真实本地 Ollama / vLLM 或其他供应商视觉模型上验收；兼容入口已实现并用真实智谱与本地协议测试接口覆盖。
- 未部署到公网服务器，也未验证具体反向代理、域名和 HTTPS 配置。
- OCR 准确性只核对了两张公开图片及一个人为错误复核案例；不提供全语料准确率保证。
- 暂不支持 PDF 直传、多页批量和扫描件版式还原。
