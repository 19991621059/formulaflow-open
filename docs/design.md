# 工作台设计

目标：让用户对照原图检查每一处文字和公式，再把修正后的内容带回自己的文档。

色彩：纸张白 `#FFFFFF`，工作台灰 `#F4F6F9`，正文深蓝 `#18283E`，操作蓝 `#245CE1`，浅蓝状态 `#EAF1FF`，成功绿 `#237A60`。错误使用语义红，仅出现在失败和校验位置。

字体：界面统一使用 Source Han Sans CN；大小为 12、14、16、24、32、56px，字重 400、500、600。源码使用系统等宽字体，公式由 MathJax 渲染。

布局：顶部无分割线的品牌和配置入口，下方是实际处理阶段。工作区左侧原图，右侧在编辑与预览之间切换，导出操作始终靠近结果。移动端依次呈现上传、进度和结果。

```
FormulaFlow                 使用指南   模型设置
文档与公式，回到可编辑的状态
上传检查 —— 图片准备 —— 模型识别 —— 结果校验
┌ 原始图片 ──────────┐  ┌ 可编辑结果 ───────────────┐
│ 选择 / 粘贴 / 示例  │  │ 编辑  预览  对照原图复核   │
│ 图像               │  │ 文字、表格、数学表达式     │
│ 文档 / 单个公式     │  │ 校验信息；Word / MD / TeX │
└───────────────────┘  └───────────────────────────┘
```

已对照需求调整：以原图和稿件作为核心视觉，不加营销卡片、装饰性数据或自动轮播；处理阶段来自服务端事件，模型计算中只显示已等待时间。复核提案需要明确接受，原识别稿可以恢复。空态说明下一步，错误包含原因、处理方法和重试入口。
